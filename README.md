# a11yHub

Hands-on, visual explainers for WCAG success criteria.

## WCAG Visual Lab

`index.html` is a single self-contained page with an interactive bench for four WCAG 2.2 criteria:

- **1.4.3 Contrast (Minimum)**: fade text until it fails, with a live contrast ratio
- **2.1.1 Keyboard and 2.1.2 No Keyboard Trap**: tab through a broken checkout, then the fixed one
- **2.4.7 Focus Visible**: find the focus with no outline, a faint one and a strong one
- **2.5.8 Target Size (Minimum)**: a tapping game that shows why 24px matters

Open `index.html` in a browser. No build step.
