# a11yHub

Hands-on, visual explainers for WCAG 2.2 success criteria. Each criterion gets a bench where you break the rule, feel the effect, then fix it.

## Pages

- `index.html`: hub for the four principles
- `perceivable.html`: Principle 1, all 29 criteria, with 16 interactive benches covering every level A and AA criterion
- `sampler.html`: the original four-criterion lab (contrast, keyboard, focus visible, target size)

Shared styles are in `css/lab.css` and the Perceivable benches are in `js/perceivable.js`.

Open `index.html` in a browser. No build step.
